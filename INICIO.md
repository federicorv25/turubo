# Empieza aquí

**Si recibiste el ZIP:** descomprímelo y ábrelo en Codex o Claude Code. El ZIP es una copia para consultar y probar. Tu asistente debe preparar un **clon Git aparte** para colaborar.

Pega esto a tu asistente:

> Soy [nombre]. Mi issue es [enlace o número]. Lee INICIO.md, AGENTS.md y docs/ENTORNO.md. Abre la issue real y lee sus comentarios. Comprueba qué herramientas tengo y qué necesito para esa tarea. Si te falta mi nombre, cuenta GitHub, correo de commits o alcance, pregúntame. Guíame para aceptar la invitación o iniciar sesión con mi propia cuenta si hace falta. Configura Git solo en mi clon e instala únicamente lo que falte. Cuando esté confirmado, crea mi rama, aplica en-curso y abre un PR Draft vinculado con Closes #N. Mientras trabaje seguirá en Draft. Cambia a Ready cuando se cumplan los criterios y hayan pasado las pruebas. No fusiones a main.

Si solo usas el chat de ChatGPT o Claude, adjunta la guía y el texto o enlace de la issue. Ejecuta sus indicaciones en una terminal o pide apoyo al equipo. Usa Codex o la pestaña **Code** de Claude para operar sobre el clon local.

**Si tienes Plus y eliges GPT‑6.1 Terra en Codex:** recomendamos velocidad **Estándar** y razonamiento **medio** para implementar una tarea acotada; **bajo** para Git, textos y ajustes simples; **alto** solo para un bloqueo difícil o revisión puntual. Una conversación por issue, con sus archivos y criterios. Consulta tu uso; no hay una duración fija por nivel. [Disponibilidad y uso de Codex](https://learn.chatgpt.com/docs/pricing).
