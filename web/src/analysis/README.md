# Los descubrimientos

Los enlaces `#/compare/earth`, `#/compare/moon` y `#/compare/mars` funcionan sin iniciar la aventura. El módulo lee `web/public/data/analysis.json`, conserva datos pendientes como no evaluados y presenta los recortes a la misma escala.

Bolivia muestra los dos lugares y permite desplegar sus tres recortes publicados. Luna y Marte presentan el hallazgo, ambos mapas, una escala, tres botones de medidas y barras con sus valores y unidades. Las fichas completas, fuentes, resolución, cobertura, limitaciones y el caso separado del Cerro permanecen disponibles. El regreso a la aventura conserva capítulo, posición y decisión.

Prueba: cambia de destino, alterna pendiente mediana/P90/desnivel, abre un producto de origen y vuelve a la historia. Compara las cifras visibles con el JSON, en español e inglés, tanto con teclado como en una pantalla estrecha.
