# Visor del relieve

El arranque muestra el estado de cada mapa en el comparador. Primero aceptar y revisar mapas 2D y su escala; si el equipo decide activar Three.js, recibe la malla real con metadatos, sin cambiar la historia. Mantener el acceso en 2D si el equipo o navegador no puede mostrar 3D. La exageración de altura, si se usa, se muestra con su factor.
